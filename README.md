# 會議室預約看板

讓同事在瀏覽器上一眼看出 3 間會議室當天哪些時段有空，並直接預約，避免重複預約（撞期）。

這是一個**純前端**的小工具：不需要安裝、不需要建置、沒有後端，雙擊 `index.html` 就能使用。資料存在瀏覽器的 `localStorage`，重新整理或重開瀏覽器後仍會保留。

> **注意：資料不會在多人之間共享。** 需求規格 [spec.md](spec.md) 原本要求「後端 API ＋ SQLite」，本專案刻意改為純前端，因此每個瀏覽器各自擁有一份資料。詳細的取捨請見 [CLAUDE.md](CLAUDE.md) 的「與 spec 的差異」。

## 功能清單

- **單日格狀看板**：橫軸為 3 間會議室，縱軸為 08:00–18:00 的整點時段（共 10 格）。已預約的格子顯示會議主題與預約人，多小時的預約顯示為連續的格子。
- **切換日期**：前一天／後一天／回到今天、日期選擇器，也可以用鍵盤 `←` `→` 切換。
- **新增單次預約**：點空格開啟預約表單，姓名與主題必填，時長以 1 小時為單位，不能超出營業時段。
- **每週重複預約**：勾選「每週重複」並指定結束日期。系統會先檢查所有場次，**任一場衝突就整批不建立**，並列出所有衝突日期。同系列的場次在看板上有週期圖示。
- **撞期檢查**：同一會議室、同一日期、同一小時只能有一筆未取消的預約，衝突時提示「此時段已被預約」。
- **時間範圍限制**：已過去的時段以灰階顯示且不可預約；只能預約今天起 4 週（28 天）內的時段。
- **取消預約（軟刪除）**：任何人都能取消，需二次確認並填寫取消人姓名，系統會記錄取消人與時間。週期性預約可選「僅此場」或「此場及之後」。
- **使用者頭像**：以姓名第一個字搭配依姓名決定的顏色；也可以在預約時自選表情符號當頭像。
- **匯出 CSV**：下載目前檢視日期的預約清單（會議室、時段、預約人），可直接用 Excel 開啟。
- **自動同步**：每 60 秒重新讀取資料並重繪看板；同一個瀏覽器開多個分頁時，其中一個分頁寫入後，其他分頁會自動更新。

所有時間一律以 **Asia/Taipei（UTC+8）** 計算，不受電腦本機時區影響。

## 如何開啟使用

1. 取得專案資料夾（`git clone` 或直接下載）。
2. 在檔案總管中雙擊 `index.html`，以**最新版桌面 Chrome 或 Edge** 開啟。
3. 點任一個可預約的空格，填寫姓名與主題後按「預約」。
4. 點已預約的格子可以檢視詳情或取消。

不需要架設伺服器，也不需要網路連線（專案沒有引用任何外部函式庫或 CDN）。

### 清除資料

資料存在 `localStorage` 的以下鍵值，要重設時可以在瀏覽器開發者工具（F12 → Application → Local Storage）中刪除：

| 鍵值 | 內容 |
| --- | --- |
| `meetingRoomBooking.v1` | 所有預約資料（含已取消的） |
| `meetingRoomBooking.lastName` | 上次填寫的姓名，方便下次填表 |
| `meetingRoomBooking.avatars` | 每位使用者自選的頭像符號 |

> `file://` 開啟的頁面，`localStorage` 是依瀏覽器與檔案位置分開存放的；換了瀏覽器或搬動資料夾，看到的資料可能不同。

## 如何執行測試

測試同樣不需要任何工具：

1. 確認 `test.html` 與 `app.js` 在同一個資料夾。
2. 在檔案總管中雙擊 `test.html`，以 Chrome 或 Edge 開啟（網址列應為 `file:///…/test.html`）。
3. 頁面頂端會顯示「通過 N 項／共 N 項」，每個測試案例會列出預期值、實際值與 ✅／❌。

目前的測試涵蓋 `app.js` 中的撞期檢查函式 `findConflicts`，包括完全相同時段、錯開時段、部分重疊、完全包含、緊鄰時段、不同會議室等情況。若頁面顯示「無法載入 app.js」，代表 `app.js` 不在同一個資料夾，或頁面不是以 `file://` 直接開啟的。

UI 層面的行為（例如必填提示、週期性預約、取消流程）沒有自動化測試，請以 [spec.md](spec.md) 第 6 節的驗收標準當作手動測試清單；其中 AC6（兩個瀏覽器同時預約）與 AC12（其他人 60 秒內看到新預約）因為沒有後端而不適用。

```
會議室系統/
├── index.html   主程式：看板畫面、HTML、CSS，以及 UI 與資料存取的 JavaScript
├── app.js       純邏輯：撞期檢查（isActive、coversHour、findConflicts），不讀寫 localStorage
```

`.vs/` 是 Visual Studio 的本機資料夾，不屬於專案。

### 程式碼導覽

`index.html` 的 `<script>` 依區塊以註解分段，主要入口如下：

- **常數**：`ROOMS`（3 間會議室）、`OPEN_HOUR`／`CLOSE_HOUR`（營業時段）、`BOOKING_DAYS`（可預約天數）、`STORAGE_KEY` 等。
- **日期與時間**：日期一律以 `'YYYY-MM-DD'` 字串表示；`taipeiNow()` 取得台北時間的「現在」。
- **資料存取**：
  - `loadData()`／`saveData()`：讀寫 `localStorage`。
  - `commitBookings(newBookings)`：**新增預約的唯一入口**。讀取最新資料 → 檢查時間範圍 → 呼叫 `findConflicts` 撞期檢查 → 立即寫回，週期性預約整批成功或整批失敗。
  - `cancelBooking(id, scope, cancelledBy)`：軟刪除，`scope` 為 `'single'` 或 `'following'`。
- **畫面**：`refresh()` 重新讀取資料並呼叫 `render()` 重繪。

### 預約資料格式

```js
{
  id: 'lx3k9a-4f8h2k1q',      // 唯一 ID
  roomId: 'room-1',           // 會議室 ID
  date: '2026-10-20',         // 日期（台北時間）
  startHour: 10,              // 開始小時（整點）
  duration: 2,                // 時長（小時）
  name: '王小明',              // 預約人
  title: '週會',               // 會議主題
  note: '',                   // 備註（選填）
  seriesId: null,             // 週期性預約的系列 ID，單次預約為 null
  createdAt: '2026-10-16T02:00:00.000Z',
  cancelled: null             // 取消時為 { by: 取消人姓名, at: ISO 時間 }
}
```

## 開發須知

開始修改前請先閱讀 [CLAUDE.md](CLAUDE.md)，重點如下：

- 只允許 `index.html`、`app.js`、`test.html` 三個程式檔，不可拆分其他檔案，也不可引入任何外部框架或函式庫（包含 CDN）。
- `app.js` 以一般 `<script src="app.js"></script>` 載入，不使用 ES module（因為頁面是以 `file://` 直接開啟的）。
- 介面文字與程式註解一律使用繁體中文。
- [spec.md](spec.md) 第 4 節「非目標」列出的功能（登入、修改預約、通知、非整點時段等）不要自行加入。
